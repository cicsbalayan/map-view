# Guide Gave Me You

> **An interactive 3D campus guide built to help students find their way.**

**Guide Gave Me You** is an interactive campus navigation web application designed to make exploring and navigating the campus easier—especially for freshmen and students who are unfamiliar with their surroundings.

Instead of relying on static maps or asking around for directions, students can explore a visual 3D representation of the campus, search for buildings and offices, and quickly access information about different locations.

## Features

* **Interactive 3D Campus Map**

  * Explore the campus through a visual 3D map.
  * Interact with individual buildings and locations.

* **Building & Office Search**

  * Quickly search for buildings and offices.
  * Select a search result to automatically focus the map on the location.

* **Location Selection**

  * Click buildings directly on the map.
  * View additional information about selected locations.

* **Office Information Panel**

  * Display information associated with campus offices and buildings.
  * Easily close and switch between selected locations.

* **Fit Map**

  * Instantly reset the camera and return to the overall campus view.

* **Search & View Tracking**

  * Keeps track of search activity and building views.
  * Provides basic usage statistics within the application.

*  **Responsive Interface**

  * Designed to remain usable across different screen sizes.

## 🛠️ Tech Stack

| Technology       | Purpose                 |
| ---------------- | ----------------------- |
| **Next.js**      | Application framework   |
| **React**        | User interface          |
| **TypeScript**   | Type-safe development   |
| **Three.js**     | 3D campus visualization |
| **shadcn/ui**    | UI components           |
| **Tailwind CSS** | Styling                 |
| **Lucide React** | Icons                   |

The repository currently uses Next.js 16, React 19, Three.js, Tailwind CSS 4, TypeScript, and shadcn-based components.

> **Make getting lost on campus a thing of the past.**

Finding a room, office, or building shouldn't require memorizing the entire campus or repeatedly asking for directions. By combining a visual 3D map with search and location information, the project provides a more intuitive way for students to discover and navigate their campus.

It can be particularly useful during:

* Freshman orientation
* Campus tours
* Enrollment periods
* Organization events
* Student services visits
* Everyday campus navigation
